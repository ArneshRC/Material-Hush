# Material Hush for Ghostty

Dark and light themes for [Ghostty](https://github.com/ghostty-org/ghostty). Part of [Material Hush](../../README.md).

## Install

Copy `material-hush` and `material-hush-light` to `~/.config/ghostty/themes/`. To follow the system appearance, add this to your config:

```conf
theme = light:material-hush-light,dark:material-hush
```
