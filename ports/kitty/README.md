# Material Hush for kitty

Dark and light themes for [kitty](https://github.com/kovidgoyal/kitty). Part of [Material Hush](../../README.md).

## Install

Copy `material-hush.conf` to `~/.config/kitty/`, then add this line to `kitty.conf`:

```conf
include material-hush.conf
```

To follow the system appearance instead, copy `material-hush.conf` to `~/.config/kitty/dark-theme.auto.conf` and `material-hush-light.conf` to `~/.config/kitty/light-theme.auto.conf`.
