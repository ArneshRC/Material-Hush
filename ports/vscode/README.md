# Material Hush for VS Code

Dark and light color themes for [Visual Studio Code](https://github.com/microsoft/vscode). Part of [Material Hush](https://github.com/ArneshRC/Material-Hush).

## Install

Package the extension from this folder and install the `.vsix`:

```sh
npx @vscode/vsce package
code --install-extension material-hush-0.1.0.vsix
```

Then run **Preferences: Color Theme → Material Hush** or **Material Hush Light**.
