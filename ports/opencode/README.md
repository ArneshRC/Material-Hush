# Material Hush for opencode

A theme for [opencode](https://github.com/anomalyco/opencode). The one file holds both the dark and light modes. Part of [Material Hush](../../README.md).

## Install

1. Copy `material-hush.json` to `~/.config/opencode/themes/`.
2. In opencode, run `/themes` and pick **material-hush**.

opencode's dark/light mode switch moves between the two modes.
