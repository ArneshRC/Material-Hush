# Material Hush for ZapFast

A dark theme for [ZapFast](https://github.com/crmne/zapfast). Part of [Material Hush](../../README.md).

## Install

1. Copy `Material Hush.json` to `~/.config/zapfast/themes/`.
2. In ZapFast, click the settings gear at the bottom left, go to **Appearance → Theme**, and pick **Material Hush**.
