# Material Hush for Claude Code

Dark and light themes for [Claude Code](https://github.com/anthropics/claude-code). Part of [Material Hush](../../README.md).

## Install

1. Copy `material-hush.json` and `material-hush-light.json` to `~/.claude/themes/`.
2. In Claude Code, run `/theme` and pick **Material Hush** or **Material Hush Light**.

## Notes

Claude Code doesn't use the theme file for inline code or code blocks. It takes those colors from the theme's base preset. These themes use the ANSI presets (`dark-ansi` and `light-ansi`), so inline code and code blocks follow your terminal's palette. Use one of the Material Hush terminal themes so they match.
