# Material Hush for Telegram Desktop

A dark theme for [Telegram Desktop](https://github.com/telegramdesktop/tdesktop). Part of [Material Hush](../../README.md).

## Install

1. [Download the theme](https://github.com/ArneshRC/Material-Hush/releases/download/telegram/material-hush.tdesktop-theme), or zip it yourself from this folder:

   ```sh
   zip material-hush.tdesktop-theme colors.tdesktop-theme tiled.png
   ```

2. Send `material-hush.tdesktop-theme` to yourself in Telegram (Saved Messages), click it, and choose **Apply this theme**.

To use a different chat background, replace `tiled.png` with your own image before zipping. Telegram tiles an image named `tiled.*` and stretches one named `background.*`.
