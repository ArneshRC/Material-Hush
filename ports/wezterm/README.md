# Material Hush for WezTerm

Dark and light color schemes for [WezTerm](https://github.com/wezterm/wezterm). Part of [Material Hush](../../README.md).

## Install

Copy `material-hush.toml` and `material-hush-light.toml` to `~/.config/wezterm/colors/`, then set the scheme:

```lua
config.color_scheme = "Material Hush"   -- or "Material Hush Light"
```
