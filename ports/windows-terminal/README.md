# Material Hush for Windows Terminal

Dark and light color schemes for [Windows Terminal](https://github.com/microsoft/terminal). Part of [Material Hush](../../README.md).

## Install

1. Open **Settings → Open JSON file**.
2. Paste the contents of `material-hush.json` into the `"schemes"` array.
3. Set `"colorScheme": "Material Hush"` on your profile.

To follow the Windows theme, paste both schemes and use `"colorScheme": { "dark": "Material Hush", "light": "Material Hush Light" }`.
